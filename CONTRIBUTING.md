# Contributing & Contribution Ownership Policy

Thank you for your interest in **Backrooms // Level 0** (`https://github.com/Vendreith/backrooms-multiplayer`).

This is an independently developed, free-to-play project maintained by **Vendreith**. Because this repository uses a **multi-component / split licensing structure** (`© 2026 Vendreith` for proprietary engine systems + `CC BY-SA 3.0` for Backrooms-derived lore/adaptations + open-source libraries), strict asset and code provenance rules apply to all external contributions.

---

## 1. Acceptance of External Pull Requests

- **Bug reports, security reports, and attribution/license corrections** are welcome via GitHub Issues (`https://github.com/Vendreith/backrooms-multiplayer/issues`).
- **External code or asset Pull Requests** are accepted **only at the maintainer's discretion** and **only after provenance verification**.

---

## 2. Mandatory Provenance Requirements for Contributors

Every pull request that adds or modifies code, audio, textures, 3D models, fonts, or lore text **must** explicitly disclose in the PR description:

1. **Authorship:** Whether the contribution is 100% original work by the contributor, derived from a third-party source, or generated/assisted by AI tools.
2. **Third-Party Dependencies:** Exact package name, version, repository URL, and SPDX license of any new library.
3. **Media Assets (Audio / 3D / Textures / Fonts):** Exact source URL, original creator, and license (e.g., CC0 1.0, CC BY 3.0, CC BY-SA 3.0, custom written permission). Unsourced files ("found on Google/YouTube/Discord") will be rejected immediately.
4. **Backrooms Lore:** Exact Wikidot/Fandom page URL and credited original author(s) if adapting community Backrooms material, plus confirmation that the contribution is compatible with **CC BY-SA 3.0**.
5. **AI-Assisted Material:** Disclosure of any generative AI assets or pasted AI snippets so provenance and copyright eligibility can be logged in `legal/ASSET_PROVENANCE.md`.

---

## 3. Prohibited Submissions

Do **not** submit:
- Ripped, extracted, or decompiled assets from commercial games or other indie Backrooms titles;
- Copyrighted music, sound effects, video clips, or photography without documented redistribution permission;
- Content containing API keys, TURN/STUN private credentials, tokens, or personal user data;
- Material under GPL/AGPL or incompatible restrictive licenses if intended for proprietary engine modules without prior maintainer approval.

---

## 4. Ownership & License Terms for Accepted Contributions

- **No Hidden Copyright Assignment:** Submitting a pull request does **not** automatically transfer ownership (assignment) of your copyright to Vendreith, nor does this project invent or impose an unsigned Contributor License Agreement (CLA).
- **Retained Copyright & Scope of Grant:** Unless you and Vendreith execute a separate explicit written agreement (such as a future formal CLA), you retain copyright in your original contribution and confirm that you have the legal right to contribute it under the license governing the specific component you modify:
  - Contributions to **CC BY-SA 3.0 Backrooms-derived components** (`legal/BACKROOMS_ATTRIBUTION.md`, level lore/adaptations) must be licensed compatibly under **CC BY-SA 3.0**.
  - Contributions to **proprietary engine modules** are accepted only with the contributor's explicit permission for Vendreith to use, modify, and distribute the contribution within the project as documented in the pull request thread (or must be submitted only if you accept that arrangement).
- **Historical Contributions:** Existing commits or prior contributions are never silently relicensed without contributor notice and consent where applicable.
