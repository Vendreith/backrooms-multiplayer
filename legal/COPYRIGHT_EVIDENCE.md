## 2. Recommended Private Evidence Preservation Protocol (For Developer Use Only)

To maintain strong proof of independent authorship **without leaking personal data publicly**:

1. **Tag Formal Releases & Sign Commits:** Enable SSH or GPG commit signing on GitHub (`git commit -S`) and push annotated Git tags (`git tag -s v1.0.0 -m "..."`) at major releases.
2. **Maintain Private Off-Git Archive:** Store raw development artifacts in private encrypted cloud storage (not inside the public Git repository):
   - Uncompressed source snapshots / `.zip` bundles dated at major milestones;
   - Early verification screenshots, WIP video captures, design prompts & shader notes;
   - Download receipts / webpage PDFs showing license URLs (`ambientCG`, `Incompetech`, `SoundBible`, `NASA/JPL`, `Backrooms Wikidot` revision snapshots).
3. **Timestamping / Escrow (Optional):** For high-value commercial upgrades, anchor release bundle SHA-256 digests with a trusted RFC-3161 timestamping authority or official copyright deposit in your jurisdiction.
4. **Never Publish Sensitive Records:** Keep personal IDs, legal invoices, email receipts, and private IP logs strictly **out** of the public repository.
